## The model: one axis at a time

Flexbox lays items out along one **main axis** (set by `flex-direction`: `row`, `column`, and their `-reverse` variants, relative to the writing mode), with a perpendicular **cross axis**. `flex-wrap: wrap` turns one line into several, and **each line is laid out independently**, which is why wrapped rows don't line up in columns. The `-reverse` directions change visual order without changing DOM or focus order.

## The `flex` shorthand

`flex` = `flex-grow` `flex-shrink` `flex-basis`. The common values: **`flex: 1`** = `1 1 0%` (share *all* space equally), **`flex: auto`** = `1 1 auto` (start from content size, share the rest), **`flex: none`** = `0 0 auto` (rigid), **`flex: initial`** = `0 1 auto` (the default: may shrink, won't grow). **`flex-basis` beats `width`** on the main axis; a basis of `auto` falls back to `width`, and then to the content size.

## The flex layout algorithm

At mechanism depth: (1) determine each item's **flex base size** and hypothetical main size; (2) collect items into lines; (3) **resolve flexible lengths**: if there's positive free space, distribute it by `flex-grow`; if negative, remove it in proportion to **`flex-shrink × flex base size`**, which is why big items shrink more; (4) clamp by min/max, freeze the violators and redistribute; (5) compute cross sizes; (6) align. ## The automatic minimum size

Flex items have **`min-width: auto`**, which resolves to the content's **min-content** size. That single rule causes the most common flexbox bugs: text that won't truncate, a `<pre>` or long URL blowing out the layout, an image that won't shrink. The fix is **`min-width: 0`** (or `overflow` other than `visible`) on the item. The reason is worth remembering: the browser is protecting your content until you say it may be crushed.

## Alignment and auto margins

**`justify-content`** distributes along the main axis (`flex-start`, `center`, `space-between`, `space-around`, `space-evenly`, `start`/`end`), with **`safe`** to avoid pushing overflowing content off the start edge where it can't be scrolled to. **`align-items`**/`align-self` align on the cross axis (`stretch` by default, `center`, `baseline`, `first baseline`/`last baseline`). **`align-content`** distributes multiple lines. And **auto margins** absorb free space: `margin-inline-start: auto` pushes an item (and everything after it) to the end, the cleanest "push the last nav item right" technique.

## `gap` instead of margins

**`gap`** (`row-gap`, `column-gap`) puts space *between* items only: no margins to cancel at the edges, no `:last-child` overrides, and it works across wrapped lines. It replaces most margin-based spacing in flex and grid.

## `order` and its accessibility cost

`order` (like `-reverse` directions) changes only the **visual** order. DOM order, reading order for screen readers and **focus order** stay the same, which can fail WCAG 1.3.2 (Meaningful Sequence) and 2.4.3 (Focus Order). Reorder the source instead; `reading-flow: flex-visual` **[Frontier]** will let the browser follow visual order.

## When flexbox is the wrong tool

Use grid for **two-dimensional** alignment, for **consistent column tracks across rows**, and for "grid-like" wrapping where the **last row should align** with the others instead of stretching. The telltale sign: `flex: 0 0 calc(33.333% - 1rem)` with margin maths.

## Flexbox in other engines: Yoga and Figma auto layout

**Yoga**, React Native's layout engine, implements a flexbox subset with different defaults: `flex-direction: column`, `flex-shrink: 0`, `align-content: flex-start`, and no `display: block`. **Figma's auto layout** is flexbox with designer vocabulary, which makes design-to-code almost mechanical:

| Figma auto layout | CSS |
| --- | --- |
| Horizontal / vertical | `flex-direction: row` / `column` |
| Spacing between items | `gap` |
| Padding | `padding` |
| Hug contents | `width: fit-content` (or `flex: none`) |
| Fill container | `flex: 1` (main axis) / `align-self: stretch` (cross axis) |
| Fixed width | `width: 240px; flex: none` |
| Space between | `justify-content: space-between` |
| Wrap | `flex-wrap: wrap` |
| Absolute position (in auto layout) | `position: absolute` inside a `position: relative` frame |
